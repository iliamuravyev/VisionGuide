# VideoGuide
Данный проект представляет собой веб-приложение, которое по загруженной фотографии генерирует краткое текстовое и голосовое описание содержимого, помогая слабовидящим пользователям ориентироваться в окружающем пространстве.

## Как использовать :
Скачать и разархивировать наш проект. Создать директорию проекта через PyCharm, скопироавть файлы проекта в новую директорию (при необходимости скачать нужные библиотеки) и написать в терминале pyhton -m uvicorn main:app --reload и перейти по ссылке в терминале.
